# 艾莎和安娜的冰堡

A storybook platformer for young children about Elsa and Anna, 艾莎 (frost) and 安娜 (nuan), in an ice castle. Chinese voice guidance, English core-word learning, desktop first.

Elsa is the solo lead (← → ↑ Space); Anna follows and helps. Existing saves keep progress and outfits while switching the lead to Elsa. Anna voices all English learning, word cards, quizzes, hints and menus; stories and memories are her conversations with Elsa. Elsa retains Chinese dialogue. There is no active third-person narrator or solo character-swap control.

Anna sounds like a little sister: she is the ElevenLabs voice-library voice "Lulu - Cute Little Witch", a native Mandarin speaker (model `eleven_v4`), one voice for Mandarin and English, each line read whole; word cards are slowed to 0.85. Elsa's Mandarin uses ElevenLabs voice "Stacy" (`elevenlabs:hkfHEbBvdQFNX4uWHqRF`, model `eleven_v4`, rate `-5%`) so the two sisters have distinct studio voices. Generating sister narration needs `ELEVENLABS_API_KEY` in the environment (never in the repository); the narration tool rejects a configuration where the two sisters share a Chinese voice.

- Play: open `ice-castle.html` from a local web server (`python3 -m http.server`), assets load from `game/`.
- Build: `cd art && python3 slice.py && cp game/* ../game/ && python3 build_page.py`.
- Development plans: [PLAN.md](PLAN.md) (kids' edition), [PLAN-2.md](PLAN-2.md) (phase two: fixes, clean-up, learning system, tablet and offline). Names that cross files: [src/CONTRACT.md](src/CONTRACT.md).
- Checks: `npm ci && make check` runs ESLint, `tsc --checkJs`, the node tests (`node test/run.mjs`, see [test/README.md](test/README.md)) and requires `ice-castle.html` to equal a fresh build; CI runs the same. After changing `src/` or the template, `make build` (= `python3 art/build_page.py`) and keep the result.
- Source layout: `src/*.js` is the logic group, `src/lib/*.js` the pure view helpers (voice queue, save, word counters, spaced review, layout, picture plan; loaded directly by the tests), `src/view/*.js` the view fragments, all inlined by `art/build_page.py`.
- Voice: `python3 art/narration.py` makes only the clips whose text or voice changed (`game/vo_manifest.json`); `--prune` deletes clips no line needs; `--dry-run` lists what would be made. Needs edge-tts and ffmpeg for a real run.
- Word exposure: `node test/exposure.mjs` prints how often each core word is heard in context per room; `--write` regenerates `src/content/exposure.md`.
- Character art: approved Grok sheet `art/raw/elsa-anna-atlas.jpg`. Run `python art/character_atlas.py` (Pillow, numpy, scipy), then `python3 art/build_page.py` to rebuild frames, portraits and title art. The full art slicer also imports this sheet last. Internal `frost` / `nuan` IDs mean Elsa / Anna and stay stable for existing saves.
- Big screens: `python art/hd.py` (Pillow, numpy, and `realesrgan-ncnn-vulkan` via `REALESRGAN`, PATH or `~/Applications/realesrgan`) makes `game/hd/`, a copy of every stage picture at twice the size: Real-ESRGAN x4 then Lanczos, `x4plus` with a light grain for the paintings, `x4plus-anime` for cut-out sprites. It only redoes copies whose picture changed (`art/hd.json` keeps the source hashes; a test fails on a stale copy). On Retina / large screens (`> 1700` device pixels), the page requests `game/hd/` directly in a single pass with automatic fallback to `game/` if an HD copy fails; otherwise, and offline, the normal picture stays. The "fast" word card is drawn from Elsa's run frame by `python art/character_atlas.py --word-fast`.
- Wardrobe: after rebuilding the characters, run `python art/recolor.py --publish` and `python3 art/build_page.py`. This writes 48 dress-colour frames (12 poses × 2 sisters × 2 extra colours), four hats and per-pose head offsets. The full art slicer does this automatically. Elsa has mint/rose gowns; Anna has teal/lilac skirts with her magenta cape preserved.
- Rooms: each of the 10 rooms has two screens (PLAN-2 E1); the first screen's door leads to the second, small stars and the memory fragment count for the whole room, and the HUD restart starts only the screen being played. Every room's automatic solution plays for at least 30 s. Clearing Room 10 opens the Grand Finale Keepsake Album showing both sisters in their chosen outfits.
- Learning: a clear page quiz and the wordbook's ear-button review game pick options from rooms already cleared (wrong words first); the recall card brings back up to two due older words; the parent settings (2 s long press on the gear) have a progress page with heard counts, first-try accuracy and play time.
- Tablet and offline: touch mode follows `(pointer: coarse)` or a first finger; portrait auto-pauses speech and shows only a turn-the-tablet picture; every target is at least 64 CSS px at 1024 x 768; the title has four main buttons; a gamepad moves a gold ring over the buttons (A presses, B goes back). Pictures load by group (title set under 2 MB first, a room's set while its cards are up), and self-hosted subsetted offline fonts (`game/font_zh.woff2`, `game/font_en.woff2` built by `art/make_fonts.py`) keep typography crisp without network access. `sw.js` (generated from `art/sw.template.js` by `art/build_page.py`) and `manifest.webmanifest` make it installable and playable offline once a room has been opened; not registered with `?dev=1` or from `file://`. Serve over HTTPS (or localhost) for the worker.
- Release package: `python3 art/package_release.py --out /path/to/elsa-anna.zip`. Includes the built page, `sw.js`, the manifest and icons, current audio/images and a checksum manifest; excludes authoring files, QA saves and obsolete narration. Serve the extracted folder over HTTP. Asset fingerprints prevent old portraits, costumes or narration from surviving a release in the browser cache.
- `castle3d/` is an earlier, shelved 3D experiment.
